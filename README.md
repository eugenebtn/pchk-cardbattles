# Карточные битвы ПЧК — онлайн

Фанатская браузерная версия настольной игры «Карточные битвы» по «Подземельям Чикен Карри»: игра с компьютером, вдвоём за одним экраном и с другом по ссылке.

Карты, персонажи и иллюстрации принадлежат «Подземельям Чикен Карри» (chickencurry.store). Тексты карт и правила — по материалам cardbattles.cc и официальным правилам авторов.

Звуки: Kenney (kenney.nl, CC0), OpenGameArt — «80 CC0 RPG SFX» (rubberduck, CC0), «Magic Spell SFX» (JaggedStone, CC0), «Fireball» (Julien Matthey, CC0), «25 CC0 bang/firework SFX» (rubberduck, CC0). Музыка: RandomMind — «Medieval: King's Feast», «The Bard's Tale», «Minstrel Dance» (CC0).

Текстуры: ambientCG (CC0). Спрайты эффектов: Kenney Particle Pack (CC0).

Проверка правил: `node tests/simall.mjs 25` и `node tests/cards_*.test.mjs`.
